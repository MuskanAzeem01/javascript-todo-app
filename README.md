# 📝 To-Do List Web App

A functional and interactive **To-Do List Web App** built with **HTML, CSS, and JavaScript**.

I built this project to strengthen my JavaScript skills by practicing **DOM manipulation, event handling, arrays, dynamic elements, and Local Storage**.

## ✨ Features

* ➕ Add new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* 💾 Store tasks in Local Storage
* 🔄 Tasks remain saved after refreshing the page
* ⌨️ Add tasks using the **Enter** key
* 🚫 Prevent empty tasks from being added
* 📝 Edit tasks directly in the task list

## 💾 Local Storage

Tasks are stored in the browser's **Local Storage**, so added, edited, and deleted tasks remain updated even after refreshing the page.

The project uses:

```javascript
localStorage.setItem()
localStorage.getItem()
JSON.stringify()
JSON.parse()
```
